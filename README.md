# Python Backend Roadmap

Учебный проект по подготовке к работе Python Backend-разработчиком.

## Цель

Изучить Python, Git, SQL, FastAPI, тестирование и Docker, а затем подготовиться к стажировке или первой работе.

## Выполненные темы

### День 1 — основы Python

- циклы;
- условия;
- функции;
- списки;
- словари;
- работа со списком транзакций;
- группировка расходов по категориям;
- разделение программы на функции.

## Файлы

- `00_python_warmup.py` — разминка по спискам, циклам и функциям;
- `01_transactions.py` — анализ доходов и расходов;
- `02_finance_report.py` — полноценный финансовый отчёт.
