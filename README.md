## Выполненные задания

### `00_python_warmup.py`

Повторение базового Python:

- обход списка в цикле;
- поиск суммы, максимума и среднего значения;
- подсчёт положительных и отрицательных чисел;
- функции и условия.

### `01_transactions.py`

Первая версия анализа финансовых операций:

- подсчёт доходов;
- подсчёт расходов;
- расчёт баланса;
- поиск самой крупной траты.

### `02_finance_report.py`

Финансовый отчёт с разделением программы на функции:

- анализ транзакций;
- группировка расходов по категориям;
- поиск самой затратной категории;
- форматированный вывод отчёта.

### `02_oop/01_transaction_class.py`

Первый класс для представления финансовой транзакции:

- создание объектов через `__init__`;
- методы `is_income()` и `is_expense()`;
- свойства `transaction_type`, `category`, `amount`;
- валидация значений через setter-методы;
- инкапсуляция с защищёнными атрибутами;
- строковое представление через `__str__` и `__repr__`;
- сравнение объектов через `__eq__`.

### `02_oop/02_finance_tracker/`

Текущая OOP-версия финансового проекта:

```text
02_oop/
└── 02_finance_tracker/
    ├── transaction.py
    ├── finance_tracker.py
    ├── main.py
    └── transactions.json
```

Уже реализовано:

- класс `Transaction`;
- класс `FinanceTracker`;
- список объектов `Transaction` внутри трекера;
- `add_transaction()`;
- `sum_income()`;
- `sum_expense()`;
- создание и добавление транзакций в `main.py`.

`transactions.json` пока не подключён — это следующий этап проекта.

## Finance Project

Первая версия консольного приложения для анализа личных финансов находится в:

```text
01_python_basics/
└── 03_finance_project/
    ├── finance.py
    ├── main.py
    └── transactions.json
```

Она умеет:

- загружать транзакции из JSON;
- проверять обязательные поля;
- проверять тип операции;
- проверять категорию и сумму;
- обрабатывать отсутствие файла и некорректный JSON;
- считать доходы, расходы и баланс;
- искать самую крупную трату;
- группировать расходы по категориям;
- находить категорию с наибольшими расходами.

Сейчас эта функциональность постепенно переносится на классы в `02_oop/02_finance_tracker/`.
