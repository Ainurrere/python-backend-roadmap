## Finance Project

Консольное приложение для анализа личных финансов.

Расположение проекта:

```text
01_python_basics/
└── 03_finance_project/
    ├── finance.py
    ├── main.py
    └── transactions.json
```

### Возможности

- загрузка транзакций из JSON;
- проверка обязательных полей;
- проверка типа операции;
- проверка категории и суммы;
- обработка отсутствующего файла;
- обработка некорректного JSON;
- подсчёт доходов и расходов;
- расчёт итогового баланса;
- поиск самой крупной траты;
- группировка расходов по категориям;
- поиск категории с наибольшими расходами.

### Формат транзакции

```json
{
  "type": "expense",
  "category": "food",
  "amount": 3500
}
```

Поле `type` принимает одно из двух значений:

- `income` — доход;
- `expense` — расход.

Поле `amount` должно содержать положительное число.

### Запуск проекта

Перейти в папку проекта:

```bash
cd 01_python_basics/03_finance_project
```

Запустить приложение:

```bash
python main.py
```
