## Практические работы

### Основы Python и анализ транзакций

`00_python_warmup.py` — упражнения на условия, циклы и функции: сумма положительных чисел, количество отрицательных, максимум и среднее значение.

`01_transactions.py` — подсчёт доходов, расходов, баланса и самой крупной траты.

`02_finance_report.py` — разделение анализа на функции, группировка расходов по категориям и вывод финансового отчёта.

### Финансовый проект на функциях

Каталог: `01_python_basics/03_finance_project/`.

Программа загружает транзакции из JSON, проверяет данные и формирует отчёт. Вычисления и валидация вынесены в `finance.py`, загрузка данных и запуск — в `main.py`.

Реализованы:

- проверка обязательных полей, типа операции, категории и суммы;
- обработка ошибок чтения файла и входных данных;
- подсчёт доходов, расходов и баланса;
- поиск самой крупной траты;
- группировка расходов и поиск самой затратной категории.

### Comprehensions и встроенные функции

`04_comprehensions.py` — фильтрация транзакций, получение уникальных категорий, создание словарей, классификация сумм и обработка вложенных списков.

`05_enumerate_zip.py` — нумерация элементов, объединение категорий и сумм, создание словаря из двух последовательностей, проверка наличия крупного расхода и положительности всех сумм.

### FinanceTracker на ООП

Каталог: `02_oop/02_finance_tracker/`.

Учебная консольная программа для анализа финансовых операций.

**`Transaction`** представляет одну операцию:

- хранит тип, категорию и сумму;
- проверяет значения через свойства;
- определяет, является операция доходом или расходом;
- поддерживает строковое представление и сравнение объектов.

**`FinanceTracker`** хранит объекты `Transaction` и рассчитывает:

- общую сумму доходов и расходов;
- баланс;
- самую крупную трату;
- расходы по категориям;
- категорию с наибольшими расходами.

**`main.py`** загружает JSON, проверяет структуру данных, создаёт объекты и выводит отчёт.

Для `Transaction` и `FinanceTracker` написаны unit-тесты. Текущая версия работает с локальным JSON и хранит объекты в памяти; база данных и HTTP API относятся к следующим этапам.

## Запуск

Нужен установленный Python 3. Для запуска тестов дополнительно требуется `pytest`.

### Клонирование

```bash
git clone https://github.com/Ainurrere/python-backend-roadmap.git
cd python-backend-roadmap
```

### Отдельные упражнения

Из корня репозитория:

```bash
python 01_python_basics/00_python_warmup.py
python 01_python_basics/04_comprehensions.py
python 01_python_basics/05_enumerate_zip.py
```

### Финансовый проект на функциях

Из корня репозитория:

```bash
cd 01_python_basics/03_finance_project
python main.py
```

### FinanceTracker на ООП

Из корня репозитория:

```bash
cd 02_oop/02_finance_tracker
python main.py
```

Финансовые проекты нужно запускать из их каталогов: путь к `transactions.json` в текущем коде задаётся относительно рабочей директории.

### Тесты FinanceTracker

Из каталога `02_oop/02_finance_tracker/`, желательно в активированном виртуальном окружении:

```bash
python -m pip install pytest
python -m pytest tests
```
